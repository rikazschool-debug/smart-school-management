- Gifted care hub (gifted/hub.tsx) tabs come from gt_me; coordinator = private._gt_coord (owner, counselor, or gifted_care manage grant); principal/vice read only with gifted_care view grant (no indicator texts).
- Nominations (gt_nominations) are written only via gt_nom_save (teacher of the student or coordinator; draft/sent), gt_nom_evidence (append) and gt_nom_act (coordinator: review/needs_info/approve/reject, reason required, nominator never decides own). One domain per student per academic year; rev guards stale edits; every change goes to gt_events. nomIssues/nomActions in model.ts mirror the server.
- An approved nomination means school care only — never official qualification or an external measure result. Old edu_records kind talent stay readable under «سجل الطلبة». Tests: scripts/gifted-e2e.ts, src/test/gifted-model.test.ts.
- Care plans (gt_plans + gt_plan_students per-student goal_status/acts_done) are written only by the coordinator via gt_plan_save/act/copy; statuses draft/ready/running/review/closed, readiness in private._gt_plan_check (mirrored by planIssues), close needs a result; after start goals/activities/students can only grow. Follow-ups (gt_followups) only via gt_plan_follow on running/review plans, immutable; a goal becomes achieved only with written evidence — activities done never count as goals. Copy carries no students, follow-ups or evidence.
- External measures (gt_measures) are coordinator-only (write and read); gt_student_file returns measures=null to others. No result ≠ not gifted.
