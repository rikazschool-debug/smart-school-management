- Central academic catalog edits are organization-owned entries layered over fixed defaults; branch allocation preserves existing IDs and history, so editing a catalog cannot silently rewrite prior school records.
- RecordForm may derive transient selectors from joined initial values; transient fields never enter the persisted payload, preserving existing column contracts.
- Academic subject creation uses transient stage/grade fields and a filtered name selector in RecordForm; they never persist links or create course assignments, preserving existing subject records and the RLS write path.
- Stage/grade preset pickers read the existing base and organization catalogs and fill the existing create form; grades resolve an available school stage ID, preserving catalog validation and owner-only writes.
- Staff-directory counts and multi-selects derive only from authorized branch rows through the directory model, keeping display classification independent of roles and accounts.- Student list filters (stage→grade→section cascade, contract type, tags) are CrudTable `multi`/`cascade` FilterDefs and `multiTags`; values are joined server-side filters, so paging and exports match the screen.
