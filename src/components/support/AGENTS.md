# support rules
- Support tickets (support_*): no direct table access; every read/write goes through support_* RPCs that derive requester/org/role from the session. Scopes: school tickets → requester, the branch principal and the org owner; platform tickets (owners/principals only) → requester and platform admins. Replies are corrected only with a kept revision, tickets are never deleted, actions are rev-checked and creates/replies/notes/info requests are idempotent by client key. Assignment grants handling of that one ticket only (support_handler); private notes stay bound to their recipient; info-request recipients read only the question via support_info_inbox; escalation copies nothing automatically. Tests: scripts/support-e2e.ts, support2-e2e.ts.
