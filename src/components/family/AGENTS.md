# family rules
- Guardian/student home reads only via family_children/family_child RPCs (server checks the link).
- fin_* tables are RPC-only; fin_pay_save is owner-only and logged; balances/payments are written only by the future financial link.
- Digital classroom = section_rooms (one per section); subject classrooms (one per course) are channels inside, linked by classrooms.section_room_id (insert trigger + ensure_classroom). Content never moves; access stays per course (can_view_course), room visible if any subject is. Regroup only via classroom_regroup (re-runnable, logs before/after report). section_room_get returns view staff|teacher|family: students only for staff_view/class teachers, guardians only for staff_view, family gets subjects+teachers only; class_group id only for active members of that conversation (never adds members). Guardian room access = verified can_follow link + child's active enrollment (follows transfers, siblings → several rooms). Sections UI: src/components/classroom-room-tabs.ts (page + sidebar). Test: scripts/classroom-room-e2e.ts (42).
- Guardian/student accounts never edit displayed records: profiles self-update excludes family-only users (_family_only()); their own actions (submissions, messages, consents, photo) write separate rows via RPCs. Test: scripts/family-readonly-e2e.ts.
