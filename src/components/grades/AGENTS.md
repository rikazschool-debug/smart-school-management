# grades rules
- Grades: grade_plans(+items, versioned; approved plans never edited, new version via gb_new_plan_version) → grade_periods → gradebooks (one per course+period, keeps its plan version) → gradebook_entries (missing/score/absent/exempt; missing never counts as zero) → grade_results (published snapshots, superseded on correction). Totals only from _gb_total (score/max×weight once). All writes via gb_* RPCs; principal/vice (_gb_admin) set up/approve/publish/reopen/decide corrections, teacher via live assignment (_gb_teacher), dept head reviews own department, owner/supervisor read-only, family reads current published snapshots only. Test: scripts/grades-e2e.ts.
- Entry: gb_save_entries (per-row errors, conflict via loaded entered_at `base`, revision bump); gb_set_entries is the legacy all-or-nothing wrapper. Window = _gb_window (period dates, gradebook reopen, grade_exceptions; locked blocks exceptions). Homework link via _gb_hw_calc (latest published attempt, never zero); drift (_gb_hw_drift) blocks approval. gb_approve binds reviewed/submitted revision; gb_publish is idempotent and needs _allow_incomplete for incomplete results. UI: src/components/grades/sheet.tsx; previewTotal in common.ts must mirror _gb_total (grades-calc.test.ts). Browser fixture: scripts/grades-browser-fixture.ts (gbx-).
