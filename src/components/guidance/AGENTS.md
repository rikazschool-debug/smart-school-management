- Student guidance hub (guidance/hub.tsx) shows tabs by edu_guidance_me; counselor = private._edu_counselor (owner, counselor role, or student_guidance manage grant) — principal/admin role alone never opens cases.
- Referral statuses draft/sent/triage/accepted/needs_info/closed; teachers only save draft or send via edu_save (private._edu_ref_check); every triage step goes through edu_ref_act, which never auto-creates a case. refIssues/refActions in model.ts mirror the server.
- Counselor-owned referral fields (class_tips, request_note, close_reason, case_id) are never writable by the teacher; teachers read referrals only through private._edu_ref_limited (no case link, no internal notes, no case-opening event).
- Board and notifications show counts, REF/CASE numbers and names only to counselors; never categories in boards or student names in notifications. Tests: scripts/guidance-e2e.ts, scripts/guidance-journey.py, src/test/guidance-model.test.ts.
- Cases: statuses draft/open/following/closed; readiness/closing/reopen rules in private.edu_case_check mirrored by caseIssues() (case-model.ts); facts, statements and assessment stay separate plan fields; cases opened from referrals start as draft. Test: scripts/guidance-case-journey.py.
- Sessions/appointments live in edu_sessions (status planned/done/missed/cancelled, mode individual/group with one row per case under group_id); only edu_case_session_save/record write them, recorded rows are immutable; group notes stay inside each case. Agenda: edu_guidance_agenda (counselor only).
- Goal progress only via edu_case_follow (progress levels; achieved needs written indicator evidence) — a done session never counts as improvement. followIssues/sessionIssues in case-model.ts mirror the server.
- Attachments via edu_case_attach (case: counselor; referral: its teacher before triage decision) into private storage, opened only by signed URL; no OCR/AI.
- Guardians get only counselor-written summaries (edu_case_shares via edu_family_guidance); family links never open the case; withdrawals keep history. Tests: scripts/guidance-run-journey.py, src/test/case-run-model.test.ts.
- Programs/annual plan: edu_programs via edu_prog_save/act/list (counselor writes; principal/vice read via private._edu_stats_ok); history in edu_program_events; programIssues mirrors _edu_prog_check.
- Reports stay separate: edu_guidance_report (names, counselor only) vs edu_guidance_stats (counts only; small category/outcome cells = -1 for non-counselors). Every export calls edu_guidance_export_log first (≤1 year, no export-all); case opens are logged inside private.edu_detail (10-min dedupe) and read via edu_access_view. Test: scripts/guidance-reports-journey.py.
