# HR rules
- Log: docs/hr/execution-log.md (update per package).
- HR attendance (hr_att_*): RPC-only; raw punches append-only and separate from computed hr_att_days; closed days change only after dated reopen; devices via signed /api/public/hr/attendance → service-only _hr_att_ingest; money effect only via payroll. Tests: hr-att-e2e, hra-journey.
- HR pay (hr_decisions/hr_advances/hr_pay_*): RPC-only; dated hr_pay_policies, unset = held. Tests: hr-pay-e2e, hrp-journey.
- HR extensions: owner switch (hr_ext_settings); recruitment hr_rc_*, convert once. Tests: hr-recruit-e2e, hrr-journey.
- Mobile punch: hr_att_self_punch always needs a fresh (≤60 s), accurate reading inside the school site (hr_att_sites) of a live assignment; only school/distance/accuracy are stored. Asset custody (hr_assets/hr_asset_custodies): one open custody per asset (unique index), never touches money. Tests: hr-loc-assets-e2e, hla-journey.
- Principals get no HR section by default (no _perm_base/template grant); access only by explicit grant.
- Personal file access: hr_employees.self_access is switched only via hr_self_access_set (HR edit perm, never by the person; owner excepted); linking/import/relink always leaves it off; every self path (_hr_*_self, hr_my_*, payslips, docs) requires it. Tests: hr-self-e2e, hse-journey.
- HR reports: only hr_report_catalog/hr_report (server catalog _hr_rep_meta); rows, masking and totals from the server; view = module view, print = hr_reports.print, export = module export; print/export logged. Tests: hr-reports-e2e, hr-pay-e2e.
- Addresses (hr_employee_addresses): only hr_address_get/save; full address needs sensitive (or own file), others see city only; logs store changed field names, never values. Hourly permissions (hr_perm_requests, five kinds): employee → direct manager → HR via hr_perm_*; server computes minutes and refuses overlaps/end ≤ start; no money effect. Opening balances (hr_open_batches): server preview → draft with source rows/total → approved by a different person only when totals match; posts append-only opening moves keyed per employee so re-import skips. Tests: hr-p10-e2e, hp10-journey.
