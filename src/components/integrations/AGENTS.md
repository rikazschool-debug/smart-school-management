# Integrations rules
- Integrations/API (api_*): owner-only RPCs; public gateway src/routes/api/public/v1/$.ts hashes the key and defers every check to service-only _api_call (scope, fields, limits, idempotency, logging); test keys and the explorer always dry-run; no DELETE; API payments wait in api_inbox for owner approval through sf_collect. Webhooks queue via _api_emit triggers (data through the key's own read scope) and are sent only by the owner's manual dispatchWebhooks until automatic sending is approved. Test: scripts/api-e2e.ts.
- Integrations v2: _api_catalog() = _api_catalog_v2 (v1 + overlay + _api_catalog_ext/_ext2) + _api_catalog_ext3 (wrapped as _api_catalog_v3) + _api_catalog_ext4; add new resources as a new _ext file rather than editing old ones (area school|central, menu/sub, sensitivity, psec = platform section; _api_exec wrapper returns 403 section_disabled when section_enabled is off, then delegates to _api_exec_v2); _api_coverage (wrapping _api_coverage_v3 → _v2) maps every perm_catalog section to resources (+ optional withheld note for partial coverage) or an exclusion reason (api_resource_directory lists unregistered sections). Keys have scope_type schools|central|mixed and explicit all_schools (empty list never means all); per-resource school_ids narrow; owner-only api_resource_set switches a resource per org (logged). Reads go through _api_rows_all (v1 + _api_rows_v2/_v3/_v4/_v5 explicit safe projections; aggregate resources hide counts below 5 where individuals could be inferred); OpenAPI/Postman downloads are built client-side from the same catalog by src/lib/api-spec.ts (never include secrets); docs/integrations-coverage.md is regenerated by scripts/api-coverage-doc.ts; _api_write wraps _api_write_v1 and adds cancel of the key's own pending inbox rows and approval-queued creates (building/bus maintenance, support) executed only by api_inbox_decide via mt_create/support_create. Tests: scripts/api2-e2e.ts, scripts/api3-e2e.ts.

- Guardian ratings reach the API only as guardian_rating_stats (one average per school+year, hidden below 5 ratings); never add teacher, guardian, student, comment or per-question fields.
