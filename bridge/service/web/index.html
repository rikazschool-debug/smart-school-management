أجهزة الحضور

حالة إدارية واضحة، وحالة مستقلة لاستقبال كل جهاز.

—
تسجيل جهاز أو تعديل بياناته

تسجيل الجهاز لا يفعّل الاستقبال أو يغير الجهاز. تغيّر SN أو الموديل أو الموقع يتطلب إعادة اعتماد الاستقبال ويحفظ السجلات السابقة.
