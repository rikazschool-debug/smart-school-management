# نظام تصميم ركاز (مرجع موحد للوحات الثلاث عشرة)

- الهوية: أخضر بترولي داكن للشريط الجانبي، ذهبي للشعار والعنصر النشط، خلفية عاجية دافئة، بطاقات بيضاء بحواف مستديرة كبيرة.
- الخط: Cairo في كل المنصة. الاتجاه RTL.
- الألوان: عبر متغيرات src/styles.css فقط (primary, muted, accent, destructive, sidebar-*). لا ألوان مكتوبة مباشرة في المكونات؛ الاستثناء الوحيد طبقة تعتيم الحوارات في shadcn.
- الهيكل المشترك: AppShell (شريط جانبي على الكمبيوتر / قائمة منسدلة على الهاتف) + محدد السياق + جرس الإشعارات.
- المكونات المشتركة: PageHeader، EmptyState، LoadingState، ErrorState (src/components/states)، CrudTable (src/components/crud-page)، Button/Input/Dialog من shadcn.
- الحالات: كل قائمة لها تحميل وخطأ مع «إعادة المحاولة» وفارغ بتوضيح؛ كل زر كتابة يعرض «جارٍ…» ويُعطَّل أثناء التنفيذ، ثم رسالة نجاح أو خطأ عربي (arabicError).
- اللوحات بلا وظائف مبنية (المرشد، الممرض، الأمن) تعرض حالة فارغة صريحة، لا أرقام مختلقة.
