# دليل مصادر البيانات للأتمتة — حصر المرحلة A

الحالة: **تحليل فقط — لم يُنفَّذ شيء من هذا الدليل بعد.** المصدر: قاعدة الاختبار بتاريخ 2026-11-26.

## 1. ما الموجود الآن

- الأتمتة اليوم تبدأ من **حدث** فقط (`au_events`، 71 حدثًا، 29 جاهزًا ومختبرًا). لكل حدث محوّل مغلق داخل `_au_src` يقرأ جدولًا واحدًا ويعيد متغيرات محددة.
- المتغيرات 106 متغيرًا موزعة على 29 حدثًا (2–9 لكل حدث). لا توجد قوائم اختيار من البيانات الفعلية: مثلًا `adm.doc.expiring` يعرض «الأيام المتبقية» و«النوع» كنص حر فقط، دون المدرسة أو المسؤول أو اختيار وثائق بعينها.
- `fin.due.overdue` مجمّع **لكل مدرسة أسبوعيًا** (`overdue_count`, `overdue_amount`) — لا يمكن به اليوم استهداف «كل طالب رصيده المتبقي ≥ 2000».
- **أساس جاهز لإعادة الاستخدام:** دليل موارد التكاملات (`_api_catalog`) يضم **74 موردًا** معتمدًا في 15 قسمًا رئيسيًا، لكل مورد: الحقول بالعربية، الحساسية، المرشحات، الترتيب، والعمليات المسموحة، مع حجب الحقول الحساسة افتراضيًا. هذا هو أقرب حصر رسمي لمصادر ركاز، وسيُستخدم **كمرجع للحصر فقط** — لا عبر مفاتيح API الخارجية.

## 2. التصميم المقترح لدليل المصادر (`au_sources`)

سجل واحد لكل مصدر، يضم:

| الحقل | المعنى |
|---|---|
| `key`, `menu`, `sub`, `label` | القسم الرئيسي والفرعي والاسم العربي (متطابقة مع دليل التكاملات) |
| `perm_section` | قسم شجرة الصلاحيات الذي يُشترط للقراءة (`perm_allows`) |
| `area` | مدرسة / مركزي |
| `fields` | لكل حقل: المفتاح، الاسم العربي، النوع (رقم، نسبة، مبلغ، تاريخ، حالة، نص، منطقي، مرجع)، مصدر القائمة للاختيار، قابل للتصفية/التجميع/الترتيب، **حساس/مستثنى** |
| `relations` | العلاقات: طالب → ولي أمر، طالب → شعبة → صف → مرحلة، موظف → مدير مباشر، وثيقة → مسؤول… (تُستخدم للمستلمين الديناميكيين وللمتغيرات) |
| `actions` | الإجراءات المسموحة على سجلات هذا المصدر |
| `risk`, `readiness`, `tested` | درجة المخاطر وحالة الجاهزية والاختبار |

**قاعدة أمان أساسية:** لا SQL حر. كل مصدر له **محوّل قراءة مغلق** (`_au_ds_<key>`) يحدد الأعمدة المسموحة؛ المرشحات التي يبنيها المستخدم تُترجم فقط إلى حقول مسجّلة ومعاملات مُمرّرة كقيم، وتُضاف دائمًا قيود المجموعة والمدارس المسموحة للمستخدم. القراءة على دفعات (ترقيم بالمفتاح، 500 سجل للدفعة) مع حد أقصى لكل تشغيل.

**قوائم الاختيار من البيانات الفعلية (`au_lookup`)**: المدارس، المراحل، الصفوف، الشعب، الأعوام والفصول، أنواع وثائق المجموعة (القيم الفعلية في `org_docs.kind`)، أنواع وثائق الموظفين (`hr_doc_types`)، أنواع الإجازات، تصنيفات الصيانة، أنواع الرسوم، الأقسام، المسميات الوظيفية — كلها مقيّدة بنطاق المستخدم.

## 3. المصادر المرشحة للدفعة الأولى (المرحلة B)

اختيرت لأنها تغطي سيناريوهات الملف الخمسة والسيناريو المالي، ومصدرها الفعلي معروف:

| المصدر | القسم | الجدول/الدالة الفعلية | الحقول الأساسية المقترحة | ملاحظات |
|---|---|---|---|---|
| حسابات الطلاب (لكل طالب) | المالية والمحاسبة | `sf_obligations` + `sf_allocations` + `sf_credit_moves` + `sf_carries` (بنفس حساب `sf_get`/`sf_arrears`) | المدرسة، العام، الفصل، نوع الرسوم (دراسية/نقل/الإجمالي)، الأصلي، المستحق، المسدد، **المتبقي**، المستحق حاليًا، الرصيد السابق، الرصيد الدائن، تاريخ الاستحقاق، أيام التأخير، نسبة السداد، حالة الطالب | قراءة فقط؛ يجب أن يطابق الرقم ما تعرضه شاشة الرسوم نفسها — يُختبر بمقارنة مباشرة |
| وثائق المجموعة | إدارة المدارس | `org_docs` | المدرسة/مركزي، النوع (قائمة فعلية)، الاسم، رقم الوثيقة، تاريخ الانتهاء، الأيام المتبقية، منتهية/سارية، مؤرشفة | «مسؤول الوثيقة» غير موجود كحقل اليوم (يوجد `created_by` فقط) — **فجوة** |
| غياب الطلاب | شؤون الطلاب | `attendance_days` | المدرسة، المرحلة، الصف، الشعبة، الطالب، الحالة، بعذر/بدون، العدد في فترة، **متتالي/متفرق**، العام والفصل | «المتتالي» يحتاج حسابًا جديدًا داخل المحوّل |
| طلبات صيانة المباني والباصات | الصيانة | `mt_*` | النوع/التصنيف، الأولوية، الحالة، أيام الفتح، المدرسة، المسؤول | يعتمد على `_mt_can_read` |
| وثائق وعقود الموظفين | الموارد البشرية | `hr_documents`, `hr_contracts` | الفرع، القسم، التصنيف، المسمى، نوع العقد، نوع الوثيقة، الأيام المتبقية، الحالة | الوظيفتان القائمتان تنبهان أصلًا؛ يلزم مفتاح منع تكرار مشترك |
| التكليفات الإدارية | الإدارة المدرسية | `adm_tasks` | موجود اليوم عبر الحدث؛ يُنقل إلى صيغة المصدر | |

بعد اعتماد الدفعة الأولى تُضاف بقية الموارد الـ74 بنفس القالب (المصفوفة في `docs/automation-coverage-matrix.md`).

## 4. مستثنى من دليل المصادر

المحادثات الخاصة؛ السجلات الصحية الفردية؛ التقييمات الفردية لأولياء الأمور؛ الرواتب والقرارات المالية للموظفين؛ السجلات التربوية الفردية؛ الصلاحيات والعضويات. الحقول الحساسة (رقم الهوية، الجوال، العنوان، الملاحظات الحرة) لا تُستخدم في الرسائل ولا تظهر في سجلات التنفيذ.

## 5. أنواع البيانات والمقارنات

المقارنات الموجودة (15) تغطي أغلب المطلوب: يساوي، لا يساوي، أكبر/أصغر (مع يساوي)، يحتوي/لا يحتوي، ضمن القائمة، بين، فارغ/غير فارغ، قبل/بعد، خلال أيام. **ينقص:** «ليس ضمن القائمة»، «تغيرت القيمة»، «تغيرت الحالة» (تحتاج حفظ لقطة سابقة لكل سجل في `au_runs`/جدول لقطات صغير)، ونوع «مبلغ» مستقل بعملة الريال.
