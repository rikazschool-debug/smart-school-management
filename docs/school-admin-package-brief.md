ابدأ بناء قسم «الإدارة المدرسية» في ركاز، ويضم:
النماذج والطلبات، والتكليفات، والمناوبات والإشراف اليومي، والاجتماعات، والمحاضر والقرارات.

المطلوب قسم عملي متكامل وبسيط الاستخدام، لا مجموعة صفحات شكلية أو سلسلة موافقات طويلة. استخدم الخدمات والمكونات الحالية، وابنِ شاشات الأدوار المتأثرة بالتوازي.

جميع الردود والتقارير بالعربية.

# 1 الثوابت وحدود النطاق

حافظ على:
- المستخدمين والأدوار والدعوات والصلاحيات للمالك وحده.
- إنشاء مجموعات التواصل اليدوية للمالك ومدير المدرسة فقط.
- الواجبات والاختبارات بآليتها المبسطة، دون موافقات إدارية على الدرجات.
- عزل المؤسسات والمدارس والأقسام والإسنادات.

لا تضف رواتب أو إجازات وظيفية أو بصمة أو مالية أو نقلًا مدرسيًا.

الزيارات الصفية وتقييم المعلمين وخطط التحسين التفصيلية تأتي في قسم الإشراف التربوي لاحقًا. يمكن ربطها بالقسم الحالي مستقبلًا، دون بناء تقييم مكرر الآن.

قبل البدء، راجع خدمات المهام والاعتمادات والملفات والإشعارات والتقويم والتواصل الموجودة، وأعد استخدامها بدل إنشاء نسخ متنافسة.

# 2 الأدوار والقوائم

## مدير المدرسة
- لوحة متابعة المدرسة.
- إعداد النماذج والجهات المسؤولة عنها.
- إنشاء التكليفات وإسنادها ومتابعتها.
- متابعة المناوبات والاجتماعات والمحاضر والقرارات.
- البحث والتقارير داخل المدرسة.

## الوكيل
- إدارة التشغيل اليومي والتكليفات والمناوبات.
- تعديل اقتراح المناوبات ونشره مباشرة.
- تنظيم الاجتماعات ومتابعة القرارات ضمن صلاحياته.
- معالجة الطلبات المسندة إليه.

## المعلم وبقية الموظفين المخولين
- نماذجي وطلباتي.
- مهامي وتكليفاتي.
- مناوباتي.
- اجتماعاتي.
- القرارات المسندة إليّ.

## رئيس القسم
- متابعة مهام واجتماعات قسمه وفق الصلاحية الحالية.
- لا يحصل تلقائيًا على إنشاء مجموعات أو إدارة حسابات.
- أي توسيع في الإسناد يحتاج صلاحية صريحة يديرها المالك.

## المالك
- مؤشرات ومقارنة الفروع والتقارير.
- إعداد السياسات المركزية ونطاق الصلاحيات.
- لا يحصل تلقائيًا على محتوى اجتماع سري أو طلب خاص لمجرد ظهور مؤشره.

الطالب وولي الأمر لا يريان صفحات الإدارة الداخلية. أي نشاط يحتاج مشاركة الأسرة لاحقًا يُربط بقناته المناسبة، لا بفتح هذا القسم كاملًا لهما.

# 3 لوحة المتابعة

اعرض بيانات فعلية:
- تكليفات اليوم والمتأخرة.
- المهام التي تحتاج ردًا أو تحققًا.
- المناوبات غير المغطاة.
- الاجتماعات القادمة.
- الطلبات الجديدة.
- القرارات المستحقة والمتأخرة.

لكل مؤشر تعريف ورابط يفتح قائمته بنفس الفلتر. لا تستخدم أرقامًا ثابتة.

وفر تصفية بالمدرسة والفترة والقسم والمسؤول والحالة، ضمن نطاق المستخدم.

# 4 النماذج والطلبات

## قوالب النماذج

وفّر إنشاء نموذج بسيط:
- الاسم والوصف والغرض.
- الجمهور المسموح.
- الجهة أو الشخص المسؤول عن استقباله.
- الحقول المطلوبة والاختيارية.
- مرفقات عند الحاجة.
- حالة مسودة أو فعال أو مؤرشف.
- إصدار للقالب.

ادعم حقولًا مناسبة مثل النص والاختيار والتاريخ والعدد والمرفق، دون تنفيذ أكواد أو صيغ يكتبها المستخدم.

ابدأ بأمثلة غير مالية وغير وظيفية، مثل طلب نشاط مدرسي أو تقرير تنفيذ تكليف أو نموذج ملاحظة تشغيلية.

## دورة الطلب

مسودة ← مقدم ← تحت المعالجة ← مكتمل أو مرفوض أو معاد للاستكمال.

استخدم مسؤول معالجة واحدًا افتراضيًا. لا تنشئ تسلسل موافقات متعددًا لكل نموذج دون حاجة صريحة.

- المرسل يرى طلباته المسموحة وحالتها والملاحظات الموجهة إليه.
- المسؤول يعالج أو يعيد أو يرفض بسبب.
- تعديل قالب لا يغير الطلبات السابقة؛ يحتفظ كل طلب بنسخة الحقول التي قدم عليها.
- امنع تعديل الطلب النهائي بصمت أو تحويله لجهة خارج النطاق.
- لا تستخدم النموذج بديلًا لتجاوز مسار موجود، مثل حساب مستخدم أو استئذان طالب.

# 5 التكليفات والمهام

أنشئ نموذج تكليف يتضمن:
- العنوان والوصف.
- المدرسة والقسم عند الحاجة.
- المسؤول الأساسي.
- مشاركين اختياريين.
- تاريخ البداية والاستحقاق.
- الأولوية.
- المرفقات.
- المطلوب لإثبات الإنجاز.
- هل يحتاج تأكيدًا من المُكلِّف بعد التنفيذ.

لا تتعامل مع إسناد المهمة لعدة أشخاص باعتباره إنجازًا جماعيًا مبهمًا؛ حدد مسؤولًا أساسيًا، أو أنشئ تكليفًا مستقلًا لكل مستلم عند الحاجة.

الحالات:
جديد، قيد التنفيذ، منجز، معاد للاستكمال، ملغى.

يمكن تفعيل «بانتظار تأكيد الإنجاز» لتكليف يحتاج مراجعة؛ لا تجعلها مرحلة إلزامية لكل مهمة.

وفر للمنفذ:
- الاطلاع والإقرار بالاستلام.
- تحديث التقدم.
- تعليق ومرفق إثبات.
- إكمال أو طلب توضيح.
- بيان تعذر التنفيذ مع السبب، دون إلغاء التكليف من طرفه تلقائيًا.

وفر للمُكلِّف:
- تعديل الموعد أو المسؤول بسبب موثق بعد بدء التنفيذ.
- إعادة للاستكمال.
- تأكيد الإنجاز عند اشتراطه.
- الإلغاء مع حفظ التاريخ.

أظهر التغييرات والإشعارات للمستهدفين دون تكرار، ولا تسمح لمشارك بتعديل مسؤول المهمة أو موعدها خارج صلاحيته.

# 6 المناوبات والإشراف اليومي

## الإعداد

أنشئ:
- مواقع المناوبة.
- أنواعها، مثل الفسحة والبوابة والممرات.
- الأيام والفترات والعدد المطلوب لكل موقع.
- الفئات المؤهلة والاستثناءات التشغيلية.
- سقف أو ضوابط العبء حسب سياسة المدرسة.

لا تربطها بإجازات HR أو استقطاعات أو أجور.

## اقتراح التوزيع

استخدم الجدول الفعال والتبديلات وعدم التوافر التشغيلي:
- استبعد تعارض الحصص والفترات.
- امنع مناوبتين متداخلتين للشخص.
- راع عدد التكليفات السابقة ومددها قدر الإمكان.
- اعرض سبب الاستبعاد أو عدم إيجاد تغطية.
- وضح طريقة الاقتراح؛ لا تدّعِ توزيعًا عادلًا دون معيار.

المقترح يبدأ مسودة. الوكيل يعدله وينشره مباشرة وفق القرار المعتمد، دون دورة اعتماد إضافية إلزامية.

## التنفيذ

وفر:
- عرض أسبوعي ويومي.
- عرض المعلم لمناوباته.
- إقرار الاطلاع.
- توثيق التنفيذ أو عدمه والملاحظات.
- طلب اعتذار أو تغيير تشغيلي يراجعه المخول.
- بديل لتاريخ محدد دون تغيير التاريخ السابق.
- إعادة توزيع عند تغير الجدول، مع تنبيه للتعارض بدل تعديل منشور بصمت.

النشر أو التعديل يبلغ المتأثرين فقط. لا تُحسب مخالفة أو عقوبة أو خصم تلقائيًا بسبب عدم الإقرار أو عدم التنفيذ.

# 7 الاجتماعات

أنشئ اجتماعًا يشمل:
- العنوان والغرض.
- المنظم.
- المشاركين من النطاق المسموح.
- الوقت والمدة والمكان، أو رابط خارجي اختياري.
- جدول الأعمال.
- المرفقات.
- مستوى الخصوصية.

لا تبنِ مكالمات فيديو داخلية ضمن هذه الحزمة، ولا تنشئ مجموعة تواصل تلقائية لتجاوز حصر إنشاء المجموعات.

وفر:
- مسودة ومعاينة ودعوة داخل التطبيق.
- قبول أو اعتذار عند الحاجة.
- تعديل الموعد أو الإلغاء مع إشعار.
- تنبيه لتعارض المشاركين مع حصص أو مناوبات.
- تسجيل الحضور الفعلي منفصلًا عن قبول الدعوة.
- تعيين كاتب محضر مخول.

قائمة المشاركين لا تكشف أرقام التواصل الخاصة. اجتماع مقيد لا يظهر عنوانه ومرفقاته لغير المخولين في البحث أو التقويم العام.

# 8 المحاضر والقرارات

## المحضر

يتضمن:
- الاجتماع والإصدار.
- الحاضرين والمعتذرين.
- الموضوعات والمناقشات اللازمة.
- القرارات.
- المرفقات.
- الكاتب وتاريخ الحفظ والاعتماد.

مسودة المحضر قابلة للتعديل للمخولين. تأكيد المنظم يثبت الإصدار؛ لا تنشئ سلسلة توقيعات طويلة افتراضيًا.

التعديل بعد التثبيت يكون بإصدار أو ملحق موثق، دون استبدال تاريخ المحضر بصمت.

## القرارات

لكل قرار:
- نص واضح.
- مسؤول تنفيذ.
- موعد.
- أولوية ومرفق عند الحاجة.
- حالة التنفيذ.
- مرجع الاجتماع والمحضر.

حوّل القرار لمهمة مرتبطة باستخدام خدمة المهام نفسها. يجب أن تكون الحالة واحدة، لا قرارًا مكتملًا ومهمة معلقة لنفس العمل بلا تفسير.

يصل المنفذ لما يلزمه لتنفيذ القرار، ولا تمنحه المهمة تلقائيًا حق قراءة كامل محضر اجتماع سري.

# 9 الملفات والإشعارات والتقويم

أعد استخدام الخدمات الحالية:
- ملفات خاصة مرتبطة بالنموذج أو المهمة أو الاجتماع.
- روابط تنزيل مؤقتة وصلاحية عند كل طلب جديد.
- معالجة الفشل والإلغاء وإعادة المحاولة.
- تنظيف الملفات المؤقتة دون حذف المرتبط.
- إشعارات الإسناد والتغيير والاستحقاق والقرار.
- منع تكرار الأثر والإشعارات عند إعادة الطلب.
- تذكير مضبوط دون إزعاج أو كشف محتوى حساس.
- ظهور المهام والمناوبات والاجتماعات في تقويم المستخدم المسموح.

لا تعتبر الإشعار دليلًا على الاطلاع أو الإنجاز. لكل منهما تسجيله المستقل عند الحاجة.

# 10 البحث والفلاتر والتصدير

من البداية، لا تؤجلها لحزمة أخرى.

وفر لكل قائمة الفلاتر المناسبة:
- المدرسة والقسم.
- النوع.
- المسؤول أو المنظم.
- الحالة والأولوية.
- الفترة والاستحقاق.
- متأخر أو يحتاج إجراء.

البحث والتصفية والترقيم تطبق على البيانات الكاملة المخولة، لا العناصر المحملة فقط.

وفر XLSX وPDF عربيين للقوائم والتقارير المسموحة:
- الطلبات ونتائجها.
- التكليفات والإنجاز والتأخر.
- جدول المناوبات والتغطية وتوزيع العبء.
- الاجتماعات والحضور.
- القرارات ومتابعتها.
- ملخص الفروع للمالك.

التصدير لا يكشف محضرًا سريًا أو مرفقًا أو ملاحظة خاصة بلا صلاحية. وضح الأعمدة والفلاتر والنطاق.

# 11 التصميم وسلوك الأزرار

حافظ على الأبيض والأخضر المزرق والرملي وخط Cairo ونظام ركاز الحالي.

استخدم:
- رأس صفحة وإجراء أساسي واضح.
- بحثًا وفلاتر متسقة.
- بطاقات هاتف بدل جداول مضغوطة.
- حالات تحميل وفراغ وخطأ وعدم صلاحية.
- تنبيه تعديل غير محفوظ.
- سجل نشاط مناسب.

الأزرار الأساسية حسب الصفحة:
إنشاء، حفظ مسودة، تقديم، إقرار، بدء تنفيذ، إكمال، إعادة للاستكمال، نشر المناوبات، تعيين بديل، دعوة للاجتماع، تسجيل حضور، تثبيت محضر، إنشاء قرار، أرشفة، تصدير.

لكل زر:
- صلاحية ونطاق.
- شروط تفعيل وتعطيل واضحة.
- تحقق خادمي.
- منع الضغط المكرر.
- انتظار ونجاح وفشل وإعادة محاولة.
- تأكيد وسبب عندما يكون للإجراء أثر يستلزم ذلك.

لا تستخدم «اعتماد» لكل فعل؛ سمِّ الإجراء بما يفهمه المستخدم.

# 12 اختبارات القبول

اختبر الخادم والمتصفح عبر المدير والوكيل والمعلم ورئيس القسم والمالك ومستخدم غير مخول:

1. إنشاء نموذج وتقديم طلب وإعادته ثم استكماله وإغلاقه.
2. إصدار قالب جديد لا يغير طلبًا قديمًا.
3. إسناد مهمة وإقرارها وتنفيذها وإكمالها.
4. إكمال يحتاج تأكيدًا وآخر لا يحتاجه.
5. تغيير مسؤول أو موعد بعد البدء مع سجل وإشعار.
6. اقتراح مناوبات دون تعارض مع الجدول، وإظهار نقص التغطية.
7. تعديل الوكيل للمقترح ونشره وظهوره للمعلم.
8. تغيير الجدول يكتشف التعارض ولا يمحو المناوبة السابقة.
9. بديل ليوم واحد مع حفظ التاريخ.
10. اجتماع ودعوة وتعديل وإلغاء وتسجيل حضور.
11. محضر مثبت ثم ملحق، وحفظ الإصدار الأصلي.
12. قرار يتحول لمهمة بحالة مترابطة.
13. منفذ القرار لا يقرأ محضرًا سريًا غير مخول.
14. رفض مدرسة أو مؤسسة أخرى من رابط وطلب مباشر.
15. رفض إنشاء مجموعة أو إدارة حسابات عبر هذا القسم لغير المخولين.
16. مرفق خاص ورفض تنزيله لغير المستهدف.
17. إعادة طلب أو تعديل من نافذتين لا يكرر السجل أو يمحو تحديثًا أحدث.
18. بحث وفلاتر وترقيم وتصدير ببيانات متعددة الصفحات.
19. الهاتف والكمبيوتر والنصوص العربية الطويلة وحالات الفشل.

افتح XLSX وPDF فعليًا وراجع الأرقام والعربية والصلاحيات.

# 13 إغلاق PDF الواجبات المتبقي

بالتوازي مع العمل المستقل، أنشئ تقرير واجبات متعدد الصفحات ببيانات اختبار:
- نزّله وافتح صفحاته بصريًا.
- تحقق من رؤوس الجداول والترقيم وعدم القص والعربية.
- تحقق من النطاق والتطابق مع الشاشة.

لا تعد فتح مسار اعتماد الدرجات القديم. سجّل النتيجة كبند إغلاق محدد.

# 14 التنفيذ والتسليم

ابدأ البناء الآن من الحد الأدنى المشترك، ثم تقدم في النماذج والتكليفات والمناوبات والاجتماعات بصورة متوازية حسب الاعتماديات.

لا تتوقف لطلب «تابع» بعد كل جزء. إذا وصلت إلى حد الجولة، احفظ نقطة استئناف دقيقة، مع آخر مهمة مكتملة والتالية، ولا تعلن اكتمال القسم.

استخدم بيانات اختبار معزولة بمعرف تشغيل ونظف مواردها المثبتة فقط. لا تعدل سجلات فعلية للاختبار.

حدّث سجلات البيانات والعقود والصلاحيات والشاشات والاختبارات. في التقرير النهائي قدم:
- ما يعمل في كل قسم فرعي وكل دور.
- القرارات التشغيلية المطبقة.
- اختبار الخادم والمتصفح والتصدير، كل منها منفصل.
- النواقص والعوائق.
- الإعدادات الخارجية والتحذيرات غير المراجعة دون وصفها بأنها آمنة.

لا تعتبر وجود الصفحات أو نجاح البناء دليلًا على اكتمال دورة العمل.
