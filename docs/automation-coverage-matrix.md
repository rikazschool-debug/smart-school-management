## التعايش مع الوظائف القائمة

اختلاف القناة أو القالب وحده لا يبرر تكرار المطالبة. تبقى الأحداث التي تنبه عليها الخدمات القائمة محجوبة؛ المسارات التشغيلية المختلفة تستخدم مصادر البيانات مع ضوابط الصلاحيات والأولوية والحدود. الربط المشترك للمطالبة المالية مع خدمة الرسوم مختبَر؛ لا يدّعي هذا الجدول اختبار كل قناة مع كل وظيفة قائمة.

## حدود المرحلة E

- خدمة حفظ ملفات PDF/Excel منفّذة ومختبرة، لكن تشغيلها التلقائي المستمر ينتظر إعداد خدمة الاختبار والموافقة؛ لا تعديل للمهام القائمة ولا نشر للإنتاج.
- مرفقات واتساب/البريد وربط مخرجات الملفات داخل القوالب غير مكتملة؛ قوالب الترويسة الإعلامية مستبعدة صراحة.
- المستند العام من قالب القاعدة المعتمد ليس خطابًا رسميًا؛ طلبات خطابات HR تبقى بشرية المراجعة.
- لا محتوى محادثات أو صحة فردية أو تقييمات أسرية فردية؛ لا تعديل أرصدة أو اعتماد سداد أو حذف أو منح صلاحيات.
- تقرير الأدلة والاختبارات والقرارات: docs/automation-platform-phase-e.md؛ لا انتقال إلى F قبل اعتماده.
